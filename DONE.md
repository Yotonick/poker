# ROYAL TABLE — что сделано (этапы 1–4 + часть 5)

Мобильная HTML5-игра Texas Hold'em для GitHub Pages и Telegram Mini App. Статика, без сборки и серверов.

## Структура
- `index.html`, `css/` — экраны, стиль (токены в `main.css`).
- `js/engine/` — движок без DOM: `cards.js` (колода, Fisher–Yates + crypto), `evaluator.js` (оценка 5–7 карт), `hand.js` (раздача: блайнды, очередь, min-raise, неполный рейз, all-in, основной/побочные банки, возврат неоплаченной ставки, ничьи с остатком, `publicView` для ботов).
- `js/bots.js` — боты (easy/normal/hard), видят только `publicView`.
- `js/progress.js` — XP/уровни, достижения, награды раз на раздачу (по `lastHandId`), `pendingHand` (выход посреди раздачи = внесённое потеряно), бесплатное пополнение (<1000 фишек, раз в 30 мин, до 3000), покупки.
- `js/game.js` — контроллер стола (боты, вскрытие, итоги). `js/sound.js` — синтезированные звуки. `js/ui.js`, `js/main.js`, `js/storage.js` (версия 2, миграция с 1), `js/collections.js` (Оникс платный: стол 3000, рубашка 2000).
- DEMO удалён.

## Дополнительно
- Подсветка выигрышных пяти карт на вскрытии (остальные общие карты затемняются).
- Категория «Фишки» (Классика, Оникс, Слоновая кость) — фишки у ставок и банка меняют цвет.
- Новая косметика: стол «Нуар» (6000), рубашка «Золото» (4000), фишки по 1500.

- Эмоции дилера: 8 портретов `assets/dealers/emo-*.webp` (нарезаны из присланного листа, фон убран по компонентам связности). Показываются в реплике дилера: новая раздача — улыбка, all-in бота — удивление, свой all-in — серьёзность, победа — радость/удивление, проигрыш — грусть, сильная рука проиграла — злость, сброс без вскрытия — подмигивание, пополнение — смущение.

## Тесты (`node tests/<имя>.test.js`)
storage, engine (комбинации, ничьи, побочные банки, min-raise, неполный рейз, фаззинг 4000 раздач; `--full` — все 2 598 960 рук), bots (1500 раздач бот-против-бота, чужих карт нет), progress.

## Проверено
Chromium headless, 390×844 и 360×640: ~11 раздач с ходами героя (в т.ч. Raise), нет горизонтальной прокрутки и ошибок JS.

## Не проверено
Реальный Telegram и телефон, звук на устройстве, баланс ботов «на слух».
